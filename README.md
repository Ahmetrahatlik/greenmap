# Greenstagram (Greenmap) 🌱

A gamified, eco-friendly social media platform where planting trees turns into real-world rewards and community building. Developed for the EIT Jumpstarter 2026, this app merges social networking, environmental activism, and AI-powered moderation.

## 🚀 Core Features
* **Interactive Planting Map:** Admins open specific geographical zones with sapling donation targets.
* **Gamification & Naming Rights:** When a forest's target is reached, the highest sapling donor wins the right to give the new forest its "meta name".
* **Reward System & E-Commerce:** Every sapling donation earns points that users can spend in the platform's integrated store.
* **Social Feed (Explore):** A dynamic feed where users can share photos, post updates, and interact through comments, similar to X (Twitter) and Instagram.
* **AI-Powered Moderation:** An integrated Large Language Model (LLM) continuously monitors the feed, automatically detecting and banning users who use profanity or toxic language.

## 🛠️ Tech Stack
* **Frontend:** React Native, Expo, TypeScript
* **Backend & Database:** Firebase
* **AI Integration:** LLM-based autonomous content moderation
* **UI/UX:** Custom mapped interfaces and interactive gamification elements
